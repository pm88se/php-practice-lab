# PHP-008 — Safe Configuration Overrides

- **Scenario:** SaaS application derives per-tenant feature flags and limits from shared defaults
- **PHP focus:** copy-on-write, reference slots, `foreach` by value vs reference, `null` overrides
- **EAV:** 20–30 minutes
- **Task:** one method, no framework or complex algorithm

## What to implement

In `src/TenantConfigOverride.php`, implement `apply(array $defaults, array $overrides): array`.

```php
$defaults = [
    'features' => ['reviews' => true, 'returns' => false],
    'limits' => ['max_exports' => 5],
];

$result = (new TenantConfigOverride())->apply(
    $defaults,
    ['features' => ['returns' => true]],
);

// ['features' => ['reviews' => true, 'returns' => true],
//  'limits' => ['max_exports' => 5]]
```

### Rules

- Exactly **two levels**: `section => setting => scalar|null`. No recursive merge, no objects, no arrays as setting values.
- Tenant settings override only named keys; omitted values inherit defaults.
- An explicit `null` overrides a default rather than meaning "missing".
- Sections or settings absent from defaults may be introduced by overrides.
- The result must be independent: later mutations to the returned configuration **must not modify** defaults, overrides, or unrelated tenant results.
- **PHP-specific edge case:** even if an input array contains reference slots (for example `['reviews' => &$flag]`), the output must not share those reference slots. Do not assume ordinary array copying always detaches references.
- Do not change the input arrays or the externally referenced variables.

### Why this is a PHP exercise

Ordinary PHP array assignment uses **copy-on-write**, so it is efficient to share an array until mutation. But PHP arrays can also contain **references**, and copying those arrays does not automatically break every reference alias. Explore the difference between copying a section wholesale and reading each scalar setting **by value** into a new array. If you use `foreach (&$value)`, remember to unset its variable after the loop.

The interesting part is PHP value/reference semantics, not a merge algorithm. Keep the implementation straightforward.
