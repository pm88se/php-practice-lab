# PHP-012 — SplHeap: bounded top-K of slow requests

**Level:** Deep  
**Mode:** Production incident / implementation  
**EAV:** 20–30 minutes

## Symptom

A worker processes millions of HTTP request metrics. An on-call engineer needs
the **10 slowest requests** for diagnostics. Sorting all metrics or keeping
them in an array causes unbounded memory growth.

Build a bounded Top-K collector using **a custom subclass of `SplHeap`**.

This is NOT PHP-003 repeated: the goal is not to execute queued jobs by
priority, but to keep the best K observations while discarding the rest.

## Contract

Complete `src/SlowRequestTopK.php`:

- `__construct(int $capacity)` rejects values <= 0 with
  `InvalidArgumentException`.
- `add(string $id, string $route, int $durationMs)` accepts a completed
  request. No need to validate durations beyond their integer type.
- At any moment, retain at most `$capacity` candidates.
- Retain **largest duration**. For equal durations, **earlier arrivals win**.
  The choice must not rely on `SplHeap` being stable (it is not).
- `count()` reports retained entries.
- `drain()` returns retained requests, **slowest first**, with earlier
  arrivals before later arrivals when durations tie; then empties the
  collector. Result entries are:
  `['id' => string, 'route' => string, 'duration_ms' => int]`.
- The collector may receive more requests after a drain.

## Technical constraints

- Implement a dedicated class extending `SplHeap` and override protected
  `compare(mixed $a, mixed $b): int`.
- Use the heap to maintain the bounded set; do not store all requests.
- Do not sort the entire input repeatedly on each `add()`.
- You may sort *only the final K results* in `drain()`.
- Prefer `O(log K)` insertion and `O(K)` retained memory.
- No additional dependencies or frameworks.

### Key investigation question

`SplHeap` treats the **greatest** item according to `compare()` as its root.
Yet to keep the K *slowest*, the candidate to **evict** is the *fastest*
among those currently retained.

What should your comparator consider "greater"? And how will you
break ties in favor of earlier arrivals?
